AUTOLUXE MOTORS

ระบบโชว์รูมซื้อ-ขายรถยนต์ออนไลน์ (Car Showroom E-Commerce System)

โครงงานสอบบูรณาการระหว่าง วิชาโปรแกรมกราฟฟิกสำหรับการออกแบบเว็บไซต์ และ วิชาการพัฒนาระบบพาณิชย์อิเล็กทรอนิกส์

ชื่อฐานข้อมูล:
car_system_db (5 Relations)
เครื่องมือที่ใช้:
HTML5 / CSS3 / JavaScript / MySQL (XAMPP)
วัตถุประสงค์และการตอบโจทย์

ภาพรวมการพัฒนาตามเกณฑ์ 2 วิชา

1. วิชาโปรแกรมกราฟฟิกเว็บไซต์ (UI/UX)

• ออกแบบธีม Luxury Dark สร้างภาพลักษณ์โชว์รูมรถยนต์หรู น่าเชื่อถือ
• จัดวางองค์ประกอบแบบ Responsive Design ดูได้ทั้งบนคอมฯ และมือถือ
• Hero Banner พร้อมปุ่ม Call-to-Action และการ์ดแสดงสเปกรถยนต์ที่คมชัด

2. วิชาพัฒนาระบบพาณิชย์อิเล็กทรอนิกส์ (E-Commerce)

• โครงสร้างฐานข้อมูลสัมพันธ์ `car_system_db` (5 Relations, PK/FK)
• ระบบค้นหา/กรองสินค้าตามยี่ห้อและราคาแบบ Real-time
• เครื่องคำนวณสินเชื่อเงินดาวน์และค่างวดต่อเดือน
• ระบบสั่งจอง/ซื้อรถยนต์ออนไลน์ พร้อมสแกน QR Code และออกใบเสร็จ (E-Voucher)

สถาปัตยกรรมฐานข้อมูล

โครงสร้างฐานข้อมูล car_system_db (5 ตาราง)

ออกแบบตามข้อกำหนด Schema และ Data Dictionary ของอาจารย์ 100%:

ตาราง (Relation) หน้าที่ในการทำงาน Primary Key Foreign Key / Reference
branch เก็บข้อมูลที่ตั้งและเวลาทำการของ 5 สาขาโชว์รูม branch_id (B001 - B005) - (ตารางแม่)
car แคตตาล็อกรถยนต์ 12 คัน (ยี่ห้อ, ราคา, สี, เครื่องยนต์, ปี) car_id (C001 - C012) - (ตารางแม่)
customer ประวัติลูกค้า 12 คน (ชื่อ, เบอร์, อาชีพ, ที่อยู่) cust_id (CU001 - CU012) - (ตารางแม่)
employee ข้อมูลพนักงานขายและผู้จัดการ 12 คน emp_id (E001 - E012) branch_id ➔ branch
sale บันทึกการซื้อ-ขายรถยนต์ (วันที่, ราคา, วิธีชำระเงิน) sale_id (S001 - S012) emp_id, cust_id, car_id
ความเชื่อมโยง

การเชื่อมโยงหน้าเว็บไซต์ กับ ตารางฐานข้อมูล

หน้าแคตตาล็อกรถยนต์

เชื่อมกับตาราง `car` ดึงข้อมูลรหัส ยี่ห้อ ราคา สี เครื่องยนต์ และปีของรถ 12 คันมาแสดงผลและทำระบบค้นหา

ส่วนแสดงสาขาโชว์รูม

เชื่อมกับตาราง `branch` แสดงจุดบริการทั้ง 5 สาขา (B001-B005) พร้อมที่อยู่และเวลาทำการ

ฟอร์มสั่งซื้อและจองรถ

เชื่อมกับตาราง `customer` (รับข้อมูลลูกค้า) และตาราง `sale` (บันทึกการขายและวิธีชำระเงิน พร้อมออก E-Voucher)

ลำดับการสาธิตระบบจริง

ขั้นตอนการนำเสนอสด (Live Demonstration)

ขั้นตอนที่ 1: หน้าร้านโชว์รูม (index.html)

1. ทดสอบ **ค้นหาและกรองยี่ห้อรถ** เช่น Tesla, BMW หรือกรองประเภทเชื้อเพลิง
2. ทดสอบ **เครื่องคำนวณค่างวดเงินดาวน์** แบบ Real-time
3. ทดสอบ **กดสั่งซื้อ/จองรถ** กรอกข้อมูลลูกค้า แนบสลิป และออกใบเสร็จ E-Voucher

ขั้นตอนที่ 2: ระบบฐานข้อมูล (phpMyAdmin & admin.html)

1. แสดงหน้า **Designer** ใน phpMyAdmin เพื่อดูเส้นความสัมพันธ์ Foreign Key ระหว่าง 5 ตาราง
2. แสดงหน้า **admin.html** เพื่อตรวจสอบข้อมูลตารางทั้ง 5 ตารางได้อย่างครบถ้วน
