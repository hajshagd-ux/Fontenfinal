# ระบบโชว์รูมซื้อ-ขายรถยนต์ออนไลน์ (AutoLuxe Motors E-Commerce)
### โครงการข้อสอบบูรณาการ 2 วิชา:
1. **วิชาโปรแกรมกราฟฟิกสำหรับการออกแบบเว็บไซต์**
2. **วิชาการพัฒนาระบบพาณิชย์อิเล็กทรอนิกส์**

---

## 📁 โครงสร้างไฟล์ในโปรเจกต์ (`C:\สอบ\Fontenfinal`)
- **`index.html`** : หน้าเว็บหลักโชว์รูมรถยนต์ (Hero Banner, แคตตาล็อกรถ, ค้นหา/กรอง, รายละเอียดสเปก, ฟอร์มจองรถออนไลน์, แนบสลิปมัดจำ, เครื่องคำนวณค่างวด)
- **`admin.html`** : หน้าแดชบอร์ดผู้ดูแลระบบหลังบ้าน (สถิติภาพรวม, ตรวจสอบรายการจอง, ดูภาพสลิปมัดจำ, เพิ่ม/แก้ไข/ลบ ข้อมูลรถยนต์ในสต็อก)
- **`car_system_db.sql`** : ไฟล์สคริปต์ฐานข้อมูล `car_system_db` (ตาราง brands, categories, cars, users, bookings) สำหรับนำเข้า phpMyAdmin
- **`css/style.css`** : ไฟล์ตกแต่งสไตล์กราฟิกแบบ Luxury Dark Showroom สวยงาม ทันสมัย และ Responsive รองรับทั้งคอมพิวเตอร์และมือถือ
- **`js/app.js`** : สคริปต์ควบคุมการทำงานหน้าบ้าน ตัวกรอง ค้นหา คำนวณสินเชื่อ และระบบสั่งจอง (บันทึกข้อมูลแบบ LocalStorage)
- **`js/admin.js`** : สคริปต์ควบคุมระบบหลังบ้าน CRUD รถยนต์ และอนุมัติการจอง

---

## 🚀 วิธีเปิดใช้งานระบบเพื่อนำเสนออาจารย์
1. **เปิดหน้าโชว์รูม (หน้าร้าน):** 
   - ดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge) ได้ทันที
2. **เปิดหน้าระบบหลังบ้าน (Admin Dashboard):**
   - ดับเบิลคลิกเปิดไฟล์ `admin.html` หรือคลิกปุ่ม **"ระบบหลังบ้าน (Admin)"** จากมุมขวาบนของหน้าแรก
3. **การนำเข้าฐานข้อมูล `car_system_db` (กรณีอาจารย์ตรวจ phpMyAdmin):**
   - เปิดโปรแกรม **XAMPP Control Panel** -> กดปุ่ม **Start** ที่ Apache และ MySQL
   - เปิดเบราว์เซอร์ไปที่ `http://localhost/phpmyadmin`
   - ไปที่แท็บ **Import (นำเข้า)** -> เลือกไฟล์ `C:\สอบ\Fontenfinal\car_system_db.sql` -> กด **Import (ลงมือทำ)**

## 🌟 ฟังก์ชันเด่นที่ตอบโจทย์ 2 วิชา

### 1. วิชาโปรแกรมกราฟฟิกสำหรับการออกแบบเว็บไซต์ (UI/UX)
- **ดีไซน์ระดับไฮเอนด์ (Luxury Aesthetic):** ใช้ธีมสีเข้มตัดทองและฟ้า (Dark Slate `#0a0f1d`, Gold `#f59e0b`, Cyan `#06b6d4`)
- **Hero Section:** แบนเนอร์ภาพรถสปอร์ตพร้อมสโลแกน และการจัดวาง Call-To-Action อย่างลงตัว
- **Car Card UI:** การ์ดรถยนต์พร้อมป้ายสถานะ (พร้อมส่งมอบ, มีคิวจอง), ไอคอนสเปกชัดเจน (เกียร์, เชื้อเพลิง, แรงม้า)
- **Responsive Web Design:** หน้าเว็บปรับเปลี่ยนขนาดและจัดเรียงองค์ประกอบอัตโนมัติตามขนาดหน้าจอ
- **Car Detail Modal:** ป๊อปอัปแสดงภาพรถขนาดใหญ่และตารางสเปกอย่างละเอียด

### 2. วิชาการพัฒนาระบบพาณิชย์อิเล็กทรอนิกส์ (E-Commerce)
- **ระบบค้นหาและกรองสินค้า (Multi-Filter & Search):** กรองตามยี่ห้อ (Toyota, Honda, BMW, Mercedes-Benz, Tesla, BYD, Porsche), ประเภทรถ (Sedan, SUV, EV, Sports), ช่วงราคา และจัดเรียงลำดับ
- **เครื่องคำนวณสินเชื่อ/ค่างวดรถยนต์ (Auto Loan Calculator):** คำนวณเงินดาวน์ ยอดจัดไฟแนนซ์ ดอกเบี้ย และค่างวดต่อเดือนแบบ Real-time
- **ระบบสั่งจองรถยนต์ออนไลน์ (Booking & Checkout Flow):**
  - เลือกว่าจะวางเงินมัดจำจองรถ หรือนัดหมายทดลองขับ
  - สรุปยอดเงินมัดจำ พร้อมแสดง QR Code พร้อมเพย์ตามยอดจริง
  - ระบบแนบหลักฐานสลิปโอนเงิน (Slip Upload) แสดงตัวอย่างภาพทันที
  - สร้างใบยืนยันการจองอิเล็กทรอนิกส์ (E-Booking Confirmation Voucher) พร้อมปุ่มพิมพ์ใบจอง
- **ระบบจัดการหลังบ้าน (Admin Portal):**
  - แดชบอร์ดสรุปจำนวนรถ, ยอดมัดจำรวม, จำนวนรายการจอง
  - ตรวจสอบสลิปและกดยืนยันการจอง
  - จัดการสต็อกรถยนต์ (เพิ่มรถใหม่, แก้ไขข้อมูล, เปลี่ยนสถานะ, ลบรถ)
  - ปุ่มรีเซ็ตข้อมูลเริ่มต้น (Demo Reset)
